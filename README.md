## 工作規則

1. 只修改自己負責的頁面；共用的 `css/style.css`、`js/main.js` 由組長修改（或先在群組說一聲）。
2. 開始工作前，先在原始檔控制按「同步變更」。
3. 圖片放在 `images/`，檔名用英文小寫加連字號（例如 `grandpa-bike-01.jpg`），每張 300 KB 以內。
4. 連結與圖片一律使用相對路徑，例如 `images/green-tunnel-cropped.jpg`，不要以 `/` 開頭。
5. 新增圖片時，同時把出處寫進 `sources.html`。
6. 重要的 Copilot 提示詞記在 `PROMPTS.md`。
7. 完成 Issue 時，在提交訊息最後加上 `closes #編號`。

## 互動元件怎麼改？

所有互動都寫在 `js/main.js`，每一段都有中文註解：

| 想改的東西 | 改哪裡 |
|---|---|
| 慢行路線的站點與說明 | `tunnel.html` 裡的 `<button class="route-stop">` 與下方 `route-detail` |
| 步數、步行速度估算 | `js/main.js` 裡的 `STEPS_PER_KM`、`MIN_PER_KM` |
| 老鐵馬零件說明 | `bicycle.html` 裡 `<span id="part-…">` 的 `data-old`、`data-now` |
| 熱點位置 | `bicycle.html` 裡 `<g class="hotspot">` 的 `cx`、`cy` |
| 承諾選項、腳印顏色 | `footprint.html` 裡的 `<input name="pledge">`、`<button class="color-btn">` |
| 碳排係數 | `js/main.js` 裡的 `FACTORS` |

**留言牆說明**：記憶分享牆與足跡牆的資料只存在每個人自己的瀏覽器（別人看不到）。要讓所有觀眾共享，建立 Google 表單＋回應試算表，把表單的「嵌入 HTML」貼到頁面取代原本的表單即可。
